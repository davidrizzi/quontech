Investment process

Three rounds, one coherent portfolio

The strategic allocation established in Round 1 remains the reference point throughout the challenge. Every later decision is evaluated as an intentional deviation from that base.

01

Strategic allocation

Build the long-term core

Broad long-only ETFs across major asset classes, selected through an explicit allocation method and calibrated to an 8% annual volatility target using 60 months of monthly USD returns.

Reference portfolio for all later rounds

02

Discretionary equity

Add researched convictions

Part of the SAA is reallocated to individual equities. Positions are supported by identifiable data, valuation and catalysts, while ex ante tracking error remains between 2% and 5%.

Active equity layer

03

Quant + macro

Systematise the active view

A factor strategy and a macro strategy are added using equities and/or ETFs. The complete portfolio remains within a 7% ex ante tracking-error ceiling versus the original SAA.

Final active portfolio

Challenge framework

Risk is defined before return is judged

The portfolio is built and evaluated under a fixed set of constraints, making risk control part of the investment process rather than an afterthought.

SAA risk

7%–9% ex ante annual volatility, centred on an 8% target and estimated from the annualised covariance matrix of the last 60 monthly USD returns.

Loss measure

1-month 5% Value at Risk, reported both as a percentage and in USD, together with a monthly-rebalanced historical backtest.

Performance

Sharpe Ratio on realised returns from the beginning of Round 1 through 27 December 2026, using the US 1-month T-bill as the risk-free rate.

Implementation

The live challenge portfolio is created in Bloomberg PRTU, monitored in PORT and reconciled with the positions reported in the team documentation.
